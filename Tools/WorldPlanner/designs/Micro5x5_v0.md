# 微型原型 5×5（v0，Claude 草案，待负责人改）

用规划器“导入 JSON”打开 `Micro5x5_v0.json`。坐标：x 向东，y 向南（y=0 是北边），单位 m。

## 框架
- 5×5 chunk（320m），外圈一圈 = 不可通行（`blocked`），但有 Biome，以后也有体素：北山地、西针叶林、东山地、南海岸。
- 中间 3×3 可玩；右上角 chunk (3,1) = 随机 chunk，其余固定。
- 随机 chunk 的上、右两边挨着不可通行圈，只有左、下两个固定邻居 → 候选出入口 2 个（A、B），每次刷新开 1–2 个。
  它是挂在固定世界上的“口袋”，不在任何必经之路上（WorldGen 第 8 节）。

## 设计顺序（本稿按此做）
1. 地点 + Biome + 水系：住所（东南，自家 chunk）、遗迹（西南）、山脚洞穴（北）、草药坡（西北）；
   一条南北向峡谷（底下有河）从北山切到南海，把地图分成西岸 / 东岸。
2. 初步路线（虚线，意图）：住所→遗迹、住所→洞穴、住所→随机区、遗迹→草药。
3. 填台地 / 盆地，让它们服务路线意图：
   - 台地（北中）：挡在住所与洞穴的直线上；上去要走峡谷东沿、从台地西端坡道上（远），
     下来可以从东南边跳下（单向近路）。台地顶还通往随机区口 A。
   - 盆地（西南，湿地）：遗迹在盆地里；从北边跳进去是单向近路，出来要走南口。
4. 最终路线（实线）：
   - 峡谷只有两处能过：**桥**（必经 1）和下游**浅滩**（必经 2，峡谷往南变浅可涉水）。
   - 去遗迹的环线：主路过桥 → 跳入盆地（单向）→ 盆地南口 → 浅滩 → 回住所。
   - 去洞穴：峡谷东沿 → 台地西端坡道 → 洞穴；回程从台地东南跳下（单向）。
   - 随机区：口 A 从台地顶进，口 B 从住所北边林地进。
