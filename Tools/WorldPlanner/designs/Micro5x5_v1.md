# 微型原型 5×5 v1（Claude 草案，替代 v0）

v0 的问题（负责人指出）：住所放射状直连所有目的地，地图没有纵深。v1 改为由地形决定通行顺序。

## 原则
- 住所只有一个出口（往西到驿站）；南是海岸，东是外圈，北是东岸高地的崖。
- 目的地按深度串联：近 = 驿站、浅滩 → 中 = 西岸、草药、桥 → 深 = 高地、洞穴、随机区。
- 去程长、回程短：单向段都是“往回走”的捷径（高地跳下 → 林地跳回住所），不是出发的近路。
- 台地 / 盆地决定顺序，而不是只挡直线。

## 道路（每条路只连两个地点）
| 路 | 方向 | 说明 |
| --- | --- | --- |
| 住所—驿站 | 双向 | 住所唯一出口 |
| 驿站—浅滩 | 双向 | |
| 浅滩—遗迹 | 双向 | 过浅滩（必经 1），从盆地南口进 |
| 浅滩—草药 | 双向 | 西岸北上，绕开盆地 |
| 草药→遗迹 | 单向 | 从盆地西侧跳进去（支线近路） |
| 草药—桥 | 双向 | |
| 桥—洞穴 | 双向 | 过桥（必经 2），走高地西端坡道 |
| 洞穴—A | 双向 | 高地顶进随机区 |
| 洞穴→B | 单向 | 从高地东侧跳下，经东北林地到 B |
| B→住所 | 单向 | 捷径：从深处跳回住所 |

初步路线（虚线）同样每条两点：住所→驿站→草药→洞穴→随机区→住所，表示“近 → 中 → 深 → 捷径回家”的意图链。

## 地形
- 东岸高地：北段（洞穴、荒原）+ 南段（针叶林），整块挡在住所与北边之间，只在西端靠桥处有坡道。
- 盆地（湿地）在西岸中部，遗迹在里面。
- 峡谷南北向，河在谷底；小溪从东边外圈流来，沿高地南脚汇入峡谷。
- 外圈不可通行；随机 chunk 在右上 (3,1)，候选口 A（高地顶）、B（东北林地）。

## 待负责人确认
- 东北林地除了跳回住所没有别的出口；随机区若关掉 B，玩家从 A 进、可以从 B 那侧的林地跳回家——符合“单行路要通往出口”的规则。
