# 微型原型 5×5 v1（Claude 草案，替代 v0）

v0 的问题（负责人指出）：住所放射状直连所有目的地，地图没有纵深。v1 改为由地形决定通行顺序。

## 原则
- 住所只有一个出口（往西到驿站）；南是海岸，东是外圈，北是东岸高地的崖。
- 目的地按深度串联：近 = 驿站、浅滩 → 中 = 西岸、草药、桥 → 深 = 高地、洞穴、随机区。
- 去程长、回程短：单向段都是“往回走”的捷径（高地跳下 → 林地跳回住所），不是出发的近路。
- 台地 / 盆地决定顺序，而不是只挡直线。

## 通行顺序（最终道路）
1. 住所 → 驿站（唯一出口）→ 浅滩过峡谷（必经 1）→ 西岸。
2. 西岸北上，绕开盆地；盆地是支线：从西侧跳进去（单向）拿遗迹，从南口出来回到西岸路。
3. 草药 → 桥过峡谷（必经 2）→ 东岸高地西端坡道 → 洞穴。
4. 高地顶 → 随机区口 A；或从高地东侧跳下（单向）到东北林地 → 随机区口 B。
5. 东北林地只能跳回住所（单向捷径）：深处回家很快，但不能从家直接去深处。

## 地形
- 东岸高地：北段（洞穴、荒原）+ 南段（针叶林），整块挡在住所与北边之间，只在西端靠桥处有坡道。
- 盆地（湿地）在西岸中部，遗迹在里面。
- 峡谷南北向，河在谷底；小溪从东边外圈流来，沿高地南脚汇入峡谷。
- 外圈不可通行；随机 chunk 在右上 (3,1)，候选口 A（高地顶）、B（东北林地）。
