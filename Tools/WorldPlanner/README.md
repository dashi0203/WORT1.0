# Wort 世界地形规划器（离线版）

## 直接使用

下载 `index.html`，**双击用浏览器打开**即可。不需要 Unity、Node、Python、服务器、网络连接或其他依赖。

- `V` 选择：选择/拖动关键地点，编辑地点、道路、河流、峡谷属性；Delete 删除。
- `B` Biome：7 种笔刷（人类区、湿地、森林、针叶林、山地、Moorland、海岸）；支持 1×1、3×3、5×5 Chunk 涂刷，右键擦除。
- `M` Chunk 标记：随机 / 固定 / 过渡 / 不可通行。**单击切换，同一块再点一次取消，拖拽可连续标记**。
- `R` 河流、`C` 峡谷：拖动绘制中心线，设置宽度（米）。
- `L` 道路：逐点画线，Enter / 双击 / “完成道路”结束；可标记单向或双向、正式道路或野外小径。
- `P` 地点：名称、类型、圆形/方形、半径（米），点击放置，可跨 Chunk。
- `H` 平移；鼠标滚轮缩放；空格拖动或中键拖动也可平移。Ctrl+Z 撤销，Ctrl+Shift+Z 重做。

在右栏可以调整世界的宽、高 Chunk 数（4–48，每块固定 64m），设置角色步行速度与现实时间的一天长度，查看穿越世界的预计旅行时间；可以一键把最外圈标记为禁行、第二圈标记为过渡。缩小尺寸会裁掉范围外的规划数据，操作前会确认。

## 数据保存

- **浏览器本地自动保存**（`localStorage`；浏览器禁用或清理数据时可能失效）。
- `导出 JSON`：下载 `wort-world-layout.json`，用于备份、导入或交给 Claude / 地形生成器参考。
- `导入 JSON`：还原先前导出的布局，会覆盖当前内容。
- `导出 PNG`：输出完整布局图，不受当前缩放/平移视角影响。

JSON 数据结构：

```json
{
  "schema": "wort-world-layout",
  "version": 1,
  "chunkMeters": 64,
  "world": { "columns": 16, "rows": 16 },
  "planning": { "speedMps": 4, "dayMinutes": 24 },
  "chunks": [{ "x": 3, "y": 4, "biome": "wetland", "zone": "random" }],
  "features": {
    "places": [{ "id": "...", "name": "沼泽入口", "category": "landmark", "shape": "circle", "radius": 40, "x": 352, "y": 448 }],
    "roads": [{ "id": "...", "name": "新道路", "type": "trail", "oneWay": true, "points": [[64, 64], [192, 128]] }],
    "strokes": [{ "id": "...", "kind": "river", "width": 12, "points": [[64, 64], [128, 180]] }]
  }
}
```

**坐标约定**：左上角为 `(0,0)`，X 向右、Y 向下；所有点、宽度和半径使用米；`chunks[x,y]` 是零起始 Chunk 索引。Biome 和固定/随机/禁行标记是两个独立维度。河流、峡谷和道路是自由折线，可以跨越 Chunk。此结构仅供规划参考，并非 Unity 地形生成器的配置文件，生成器如何消费应由后续开发决定。

## 边界和非目标

工具只编辑**布局计划**，不实现地形高度图、体素、碰撞、Biome 过渡、地形生成或路径可达性校验。地图标记、关键地点与线条不会直接改变 Unity 世界。

全部源代码放在单个 `index.html` 中，便于离线分发、复制和后续小步修改。不会修改 Wort 现有生成器或 GDD。
