## 随机 chunk 刷新原型（2026-11-11，第一版）

- 代码：`Assets/Wort/Scripts/Generation/RandomRegion.cs`（纯 C#，规则见《随机区域与关卡生成》）；预览 `--random [--seed 3] [--refresh 6]`。
- 做法：接缝带内收（3.5–6m，内缘弯曲，贴外圈的部分沿用外圈高度、贴固定平地的部分渐变到房间地面）→ 按房间区总面积随机切矩形（参数见 `RandomRegionSettings`）
  → 扭曲坐标后的 1–3m 窄墙（比墙脚和旁边接缝带都高 ≥ 2）→ 随机深度优先的连接图（链为主、偶有 3 通、可加一条成环），多方案按出入口间路程打分
  → 开口（≥ 3m，偶尔很宽）→ 单向落差（环上地面差 1 层的边，开口做成上 1 下 2 的坎）→ 浅水 / 石块 / 草丛 → 校验 → 危险区 / 奖励。
- 校验：开放出入口互通、无困死格、所有房间可达、封口有效（不走出入口通道进不了房间）、无连续斜坡；不通过就换种子（最多 24 次）。
- 结果（种子 3，chunk (3,3)，6 次刷新）：全部一次通过，每次 15–65ms；每次 4 个房间、3 条连接；危险区 1–2、奖励 1。
- 第二版：墙线扭曲加大（±3.2m）、房间角磨圆；切房间时避开出入口通道延长线（两侧 4m）；开口 / 通道南侧 3 格内的墙压到最低；预览加台地图（relief_k）和错切相机（shear_k）。
- 第三版：随机区域 = 整个 chunk（只除去河 / 水），伸进来的外圈高地也重新生成（负责人：接缝带已经负责融合）；可切面积约 3100 m²。
- 第四版：外圈挨着随机 chunk 的一段烘焙时压低（`TerraceFieldSettings.RandomChunks`，离随机 chunk 越近越低，每约 7m 一级）；接缝带贴高地的部分逐级下降（每级 2 层）；
  墙改成自然地形样（扭曲 ±5m + 细节、宽约 1–4m、岩块、墙顶高低不平）；接缝带内缘 1.5–6m 弯曲；房间最长边 50m。6 次刷新全部通过，部分要重试 2–12 次（≤ 0.6 秒）。
- 第五版：自然地形房间改用 Voronoi（`RandomRegionSettings.NaturalRooms`，false 时用矩形给地牢）；接缝带与外圈墙合成一道脊（外侧每级 2 层往上），去掉“画框”。6 次刷新全部通过，3–5 个房间。
- 第六版：地面高度场以出入口为准（各出入口外侧高度按距离插值 + 平缓起伏）；房间区轮廓有机（外围山体 1–10m、四角更厚、逐级升高）；
  北侧台阶等高线错落、台阶边石柱、崖脚碎石；接缝带外侧取附近所有固定格的最高值（修掉了与固定台地连成口袋的困死格）。6 次全部通过，3–4 个房间（可切面积约 2300–2500 m²）。
- 第七版（负责人：墙太多、接缝余量没用来融合）：接缝带只做融合（平滑过渡、每格 ≤ 1 层），去掉脊和外围山体，只留房间区外沿一道墙；四角磨圆。6 次全部通过，3–5 个房间（约 3300 m²）。
- 第八版：房间区轮廓 = 大尺度噪声团块（`RoomAreaShare` 0.62，可凹可凸可偏），其余是 Voronoi 山包（`Hill`）；接缝带 1–6m 宽窄不一；
  跳跃安全：`Reach` 加跳跃边（水平 ≤ 3.2、最多高 1 层、中间无遮挡），墙 / 山体顶 ≥ 周围 4 格内能站处 + 2，校验硬检查“墙顶 / 山体不可被够到”。
  6 次全部一次通过；房间区约 2050 m²，按房间平均面积 800 m² 只切出 2–3 间（待定：调到约 500 m²）。出入口通道穿过山体时是直的，偏长。

  （`TerraceFieldSettings.RandomChunks` 不为空时才生效，默认种子的 checksum 不变）。6 次全部通过。

## 地形生成管线（`RegionGenerator.Run`）

1. Biome 布局：程序自由发挥（北山地 → 针叶林 → 混交林；中南人类区；西南沼泽）。
   山地边界 = 山地分数 > 0：两层域扭曲 + 中频 + 南北向指状噪声做山嘴 / 山湾；按 4m 块量化 + 随机抖动。
2. Biome 权重：3 次盒式模糊（半径 16），过渡带约 40m。
3. 宏观高度：Biome 参数混合 + 域扭曲低频 / 中频噪声（山里压低 70%）。
   山前：陡段整崖 4–8 层；其余段先 2–3 级 1 层台阶（每级 5–8m 宽）再接剩余崖高。
   冲沟：5–7 条，从山体内部沿下坡追踪，出山后再延伸约 14m，宽 4–8m；冲沟里山体抬升只留 35%、清除台地。
4. 微起伏：按 Biome 混合幅度（0–1 层 ≈ 0.6，0–2 层 ≈ 1.2）。
5. 台地：每级独立块状噪声，覆盖率随位置缓慢变化；Close(2) → 4m 块量化 → Open(4) → 嵌套内缩 3m → 去小块。
   残丘：山外 7–80m，2 层，越远越稀。
6. 量化与清理（去单格凸起 / 小坑）。
7. 高台（4–5 层）；孤峰（4–7 个，山脊 / 最高处且靠崖边，直径 4–8m，高 6–10 层，外缘低 1–2 层，脚下 1 层碎石台阶）。
8. 水系：池塘 / 浅洼（水面比岸低 1 层）、人类区一个湖、一条从山里冲沟流出的河（沿低频噪声零线弯曲，水面单调不升，标记落差点）。
9. 悬崖背面遮挡带：抹平 1 层起伏，不放斜坡和坡道。
10. 连通性：小封闭区填平，大的在笔直崖边放 2–3 格宽坡道（不朝北）；再按 Biome“每块台地的坡道”数补足。
11. 斜坡（GDD 6.3【已定】：1 层高差默认是台阶）：目标 2.5% 地表格（`SlopeTargetRatio`），
    成段 2–6 格同向，优先水边 / 通行路线 / 谷底 / 长而缓的起伏带；**自然地形不允许连续两格斜坡**（坡道口除外）。

阶段 B：`RegionVoxels` 体素化（整格 + 4 向斜坡，地下到 −16 层），`ChunkMesher` 出网格（按材质分子网格，Unity 绕序）。

## layout 管线（`LayoutGenerator`，Docs/WorldGen.md）

文件：`Json.cs`（极简 JSON 读取）、`WorldLayout.cs`（数据模型 + 有机形状）、`LayoutGenerator.cs`、`LayoutChecks.cs`（可站立表面图 + 检查）；
数据：`Assets/Wort/Data/Layout/Test8x8.json`、`SiteTemplates.json`。

第一版（自己生成开放区高度）被否：开放区只有 0 层 + 微起伏，没了大走势；测试 layout 是机制清单拼出来的（直条台地、蛋形台地、东西向峡谷）。
现在的做法：**自然地形沿用 `RegionGenerator`**，给它加了可选的 `TerrainHooks`（Biome 图、保留区、河的终点、印章回调、出生点），
不传钩子时与旧版逐格一致（checksum 未变）。

1. 区域形状：椭圆 / blob（控制点 + Chaikin 3 次平滑）/ stroke（粗折线），**坐标扭曲**（大尺度约为尺寸的 18%，小尺度 1–4m）+ 线条宽度 0.55–1.6 倍变化 + 崖线粗糙；
   1m 栅格化；小于 48 格的碎块和结构区域的孤岛并入周围区域。
2. Biome 图取所在开放区；峡谷等结构区域不写 biome 时沿用下面的开放区。
3. 保留区：结构区域外扩 4m、地点 + buffer、桥和隧道走廊 → 旧生成器在这里不放台地、残丘、高台、孤峰、池塘，河绕开。
4. 印章（河之后、连通性修复之前）：海（0 层水面，海底 −3 到 −6）、峡谷（周围平滑地面 + level，谷底相邻格差 ≤ 1，边界 ≥ 2 层崖）、
