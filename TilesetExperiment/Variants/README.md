# 崖壁贴图变体：挖空填充模板

每套 Biome 一个目录（`OliveStrata` 沼泽、`RustCrag` 森林、`Limestone` 人类区），每种尺寸一组：

| 文件 | 说明 |
|---|---|
| `<尺寸>_template.png` | 1×1 基础块平铺，四周各留一整格作上下文，中间挖空处填品红（255, 0, 255） |
| `<尺寸>_mask.png` | 白 = 要填的区域，黑 = 上下文 |

尺寸以“宽×高”（格，1 格 = 1m = 512px）计：`2x1` 画布 4×3 格，`1x2` 画布 3×4 格，`2x2` 画布 4×4 格。

## 交付

填好的图存为 `<尺寸>_v<序号>.png`（如 `2x1_v1.png`、`2x1_v2.png`），与模板同尺寸、RGB，放在同一目录。同一模板可以填多次，每次一个变体。

## 填充要求（给绘图方）

1. 只画品红区域；上下文区域改动了也没关系（只会取中间那块），但不要改变画面比例和尺寸。
2. 风格、配色、石块大小、笔触、光照方向都和周围一致，看起来像同一面崖的另一段。
3. 画新的石块排列，不要复制或镜像周围已有的石块。
4. 石缝、岩层要和四周自然接上；每 512px 的格线位置不能看出接缝或规律。
5. 正面平视，不要透视、天空、植物、文字、水印；不要很重的投影或很亮的高光点。

## 之后（云端处理）

取中间区域 → 边缘一窄带换回基础块并向内渐变 → 自动检查（边缘差、亮度色调、格线痕迹）→ 生成高度与无缝法线 → 切成 512 的格 → 放进 3×3 邻居渲染预览。
