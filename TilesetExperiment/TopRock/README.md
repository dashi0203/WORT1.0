# 顶岩贴图：1×3 竖条挖空填充模板

每套 Biome 一个目录（`OliveStrata` 沼泽、`Limestone` 人类区；森林等崖壁重画后再出）。

`toprock_template.png`（512×1536，1 格 = 1m = 512px）从上到下：
- 上格：泥土（崖顶表面），底边挖了不规则缺口（深 15–35cm，偶尔更深），对应游戏里泥土离崖边往里收；
- 中格：黑色，待填——从正上方俯视的“顶岩”（崖顶露出来的岩石）；
- 下格：崖壁正面（现在用的原色图）。

这个竖条就是游戏镜头里的样子：顶面在画面上就在正面的正上方。`toprock_mask.png` 白 = 要填的区域（中格 + 泥土缺口）。

交付：`toprock_v1.png`，与模板同尺寸、RGB，放在同一目录。只取中格当顶岩；四方连续、法线由云端处理
（`Tools/TilesetBake/make_tileable.py`，法线不做向下延伸）。
