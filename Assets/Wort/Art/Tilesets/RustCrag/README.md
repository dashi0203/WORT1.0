# 红褐裂岩

侧面采用暗红色块石和不规则裂缝，地表为红褐色碎土。 打开 RustCrag_Showcase.unity 查看单层十字与 1–3 层台地。场景内地形由本目录下的 Prefab 实例拼装。

- 顶面每格 1 m × 1 m，原点在西南角。Top_E0 用于平地。其余 Top_E 的十六进制数字表示露边：东 1、北 2、西 4、南 8，组合时把数值相加。C 后缀为凹角，东北 1、西北 2、西南 4、东南 8；只在相邻两条边不露出而斜邻较低时使用。
- 崖壁每段宽 1 m、高 1 m，32 个三角形。原点在左下角，沿本地 +X 延伸，正面朝本地 −Z。绕 Y 轴旋转 90° 的整数倍可换朝向。
- 用 Crown 接顶面，用 Repeat 向下叠层。Front 适合正面，Side 有轻微轮廓变化。A、B 的材质与形状可混搭，接口尺寸一致。
- 地表和岩壁颜色取自参考图对应地块。法线从原图纹理推导，可在各材质调整强度。贴图包含参考图的部分光照信息。
- 这套资源负责地形外观。碰撞由项目的体素层处理。

## 崖缘

崖缘取自新参考中的红褐岩片，顶面露岩和崖壁上沿共享同一段投影，裂缝沿倒角延续。 Crown 使用独立的崖顶法线和颜色贴图，底端仍与 Repeat 对接。崖缘贴图只用于露边和凹角。
