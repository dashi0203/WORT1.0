# 砂土与石灰岩地块

打开 `Limestone_Showcase.unity` 可以查看单层十字形和 1–3 层台地的拼装。场景内的每一段都是可独立拖入场景的 Prefab。

## 网格与拼装

- 顶面以西南角为原点，覆盖 1 m × 1 m。将原点放在所在格的顶面高度。平地使用 `Top_E0_C0`。
- `Top_E*_C*` 的后缀是十六进制位遮罩。E 表示低于本格的四邻，C 表示四邻同高或更高、但斜邻低于本格时要补上的凹角。把需要的方向数值相加再换算成十六进制。
- E 的位值依次为东 1、北 2、西 4、南 8。C 的位值依次为东北 1、西北 2、西南 4、东南 8。示例：只露南沿用 `Top_E8_C0`，只有东北内角用 `Top_E0_C1`。
- 崖壁原点在左下角，沿本地 +X 延伸，正面朝本地 −Z。墙件宽、高各 1 m。南边直接放置，东西北边绕 Y 轴转 90° 的整数倍并对齐端点。
- 崖顶一层用 `Crown`，以下各层用 `Repeat`。使用 `Front` 做平顺正面，`Side` 做轻微起伏侧面。A、B 可以混用，各接缝的顶点位置和法线相同。
- 崖壁每件 32 个三角形。裂缝、岩块边缘与层理主要来自平铺法线贴图，可在 `CharcoalCliff` 和 `PaleLimestoneLip` 材质上调整法线强度。
- 这些 Prefab 用于美术拼装，碰撞仍由项目的体素层负责。示例场景独立于 Terrain Lab。


## 材质来源

砂土、浅色石灰岩和深色崖壁取自参考图左侧地块可见表面的投影，贴图边界经过平铺处理。崖面法线从这些岩块的明暗与边缘推导，原图的部分光照仍留在颜色贴图里。参考图未显示的背面沿用同一套材质。
